# Исследование влияния dropout на ландшафтную меру сложности нейросети

Учебная исследовательская работа, выполненная в МФТИ в рамках курса **«Практика ведения научных исследований»** под руководством **А. В. Грабового**.

**Автор:** Глезин Родион Романович.

## О работе

Цель работы — экспериментально исследовать, как вероятность dropout влияет на ландшафтную меру сложности нейросетевой модели.

Рассматриваемая мера характеризует разброс индивидуальных матриц Гессе функции потерь относительно их среднего по выборке. Она позволяет оценивать, насколько различается локальная кривизна функции потерь для разных объектов.

Эксперименты проводятся на датасете **CIFAR-10** с использованием свёрточных нейронных сетей.

## Методы

В работе рассматриваются два подхода:

- **Приближённая оценка для последнего линейного слоя:** произведения Гессиана на вектор (Hessian-vector products, HVP) и степенной метод для оценки спектральной нормы.
- **Прямое вычисление для малой модели:** построение полных матриц Гессе по всем обучаемым параметрам и вычисление спектральных норм их отклонений от среднего.

Для разных значений вероятности dropout проводится обучение моделей и оценивается ландшафтная мера сложности.

## Что исследуется

- Зависимость ландшафтной меры сложности от вероятности dropout.
- Различия между оценкой по последнему слою и оценкой по всем параметрам модели.
- Вычислительные ограничения двух подходов и чувствительность оценок к выбору подвыборки.
